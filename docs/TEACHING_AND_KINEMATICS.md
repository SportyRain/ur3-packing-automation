# 티칭 및 로봇 자세 정책

## 문제 정의

서로 다른 두 TCP pose가 각각 도달 가능하더라도 두 점 사이를 장거리 `MOVEL`로 직접 연결하면 중간 Cartesian pose에서 UR3가 물리적으로 만들기 어려운 관절 조합이 요구될 수 있습니다.

따라서 이 프로젝트는 장애물 회피가 아니라 **로봇 자체의 기구학적 자세 전환 안정성**을 우선합니다.

## HOME

HOME은 UR factory zero pose가 아닙니다. 사용자가 실제 셀에서 티칭하는 안전한 joint-space 경유 자세입니다.

권장 HOME:

- 팔을 완전히 펴지 않음
- 어깨/팔꿈치가 편안하게 접힘
- Wrist가 회전 한계 근처가 아님
- P1~P4 방향으로 이동하기 좋은 중앙 자세

## 작업점 저장

각 작업점마다 두 값을 같이 저장합니다.

- TCP pose
- 실제 6축 joint posture

저장된 joint posture는 동일 계열의 IK branch를 선택하기 위한 기준으로 사용합니다.

## 이동 정책

- station 간 장거리 이동: `MOVEJ`
- 서로 다른 station 사이: HOME 경유
- 접촉 작업 직전/직후: 짧은 `MOVEL`
- 포인트가 약 ±100 mm 바뀌면 해당 포인트만 다시 티칭

## 한계

이 구조는 MoveIt과 같은 전역 collision-aware planner가 아닙니다. 목적은 작업셀에서 반복되는 고정 포장 시퀀스의 관절 자세 안정성과 현장 수정성을 확보하는 것입니다.
