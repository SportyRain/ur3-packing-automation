# V8 — CB3 compatibility fix

## 발견된 실제 팬던트 오류

V7을 UR3 CB3 / PolyScope 3.15.8에서 컴파일했을 때 다음 오류가 확인되었습니다.

```text
컴파일 오류: 'getj' 함수 정의되지 않았음
오류 위치: global PACK_HOME_Q = getj()
```

## 원인

V7에서 현재 6축 관절 위치를 저장하기 위해 `getj()`를 사용했으나, 해당 함수는 이 컨트롤러의 URScript 함수가 아닙니다.

## 수정

모든 `getj()` 호출을 공식 URScript 함수로 교체했습니다.

```text
get_actual_joint_positions()
```

이 함수는 현재 실제 관절 엔코더 위치 6개를 radians 벡터로 반환합니다.
