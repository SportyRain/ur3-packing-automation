# UR3 PACKING V4

- 그리퍼는 TOOL DO가 아니라 일반 Control Box DO 사용
- 모든 그리퍼 출력은 `set_digital_out()` 사용
- 시작 시 I/O 주소 입력/수정 가능
- PLC START: 일반 DI [0..7]
- UR DONE: 일반 DO [0..7]
- Gripper A/B: 일반 DO [0..7]
- UR DONE, Gripper A, Gripper B는 서로 다른 DO 주소 사용
- 모든 이동 포인트마다 START 한 번 -> 포인트 하나 이동 -> DONE 한 번
- P2 밑판 접기 완료 전에는 PLC가 다음 START를 주지 않음
- P3 뚜껑 닫기 완료 전에는 PLC가 다음 START를 주지 않음

문제점: TCP pose 중심 `MOVEL` 경로 때문에 station 사이에서 관절 자세가 물리적으로 불리한 경로를 선택할 수 있었음.

상태: 실제 팬던트 로딩/실물 동작 `NOT_VERIFIED`
