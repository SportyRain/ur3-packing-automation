# V10 변경 기록

## 배경

사용자가 거의 실제에 가까운 HOME + 7개 작업점 + I/O 값을 PolyScope Installation Variables에 저장하여 제공했고, V9 실물/오프라인 검토에서 다음 사항이 확인되었습니다.

- `PACK_*` 값이 실제 `.variables` 파일에 저장됨.
- HOME 및 7개 작업점의 TCP pose와 joint posture가 일관됨.
- P3 제품투입에서 local `-Z` 100 mm 접근점은 실제 UR3 자세에서 IK 한계를 넘음.
- V9는 사이클 시작 전에 7개 접근점 IK를 모두 검사하여 뒤 단계 문제도 P1 시작 전에 전체를 막음.
- 프로그램 재시작 시 PLC DONE 출력은 메뉴보다 먼저 LOW로 초기화하는 편이 안전함.

## V10 최소 수정

1. `P3_PRODUCT_INSERT`의 접근/이탈 거리만 100 mm → **70 mm**로 변경.
2. 접근점 IK 계산을 사이클 시작 일괄 계산에서 **각 공정 STEP 직전 계산**으로 변경.
3. 저장된 I/O 설정이 유효하면 프로그램 시작 직후 **DONE LOW**를 먼저 적용.
4. 기존 7회 START/DONE handshake, HOME 경유 MOVEJ, 작업점 주변 MOVEL, Standard Control Box DI/DO, `get_actual_joint_positions()`는 유지.
5. 사용자가 제공한 거의 실제 HOME + 7개 작업점 + I/O 값을 `UR3_PACKING_V10.variables`에 보존.
