# UR3 PACKING V7

사용자가 제공한 `packing2.variables`를 확인했을 때 timestamp만 있고 `PACK_*` 티칭값은 없었으며, `packing2.installation`에도 `PACK_*` 값이 없었습니다. 따라서 V4에서 티칭한 실제 좌표는 해당 파일들만으로 복구할 수 없었습니다.

변경:

- 기존 로봇 백업의 `Box_Gripper1` TCP / Payload 0.5 kg 정보를 `packing2.installation`에 반영
- 그리퍼는 일반 Control Box DO 사용
- HOME 안전 관절자세 추가
- 7개 작업점마다 TCP pose + 실제 6축 joint posture 저장
- 다른 station 이동은 HOME을 경유한 `MOVEJ`
- 작업점 주변 짧은 접근/이탈만 `MOVEL`
- 포인트 위치가 약 ±100 mm 바뀌면 해당 포인트만 `Modify`하여 새 TCP + joint posture를 다시 저장
- 실행 시 현재 티칭 pose 기준 approach IK를 다시 계산
- 모든 HOME/접근/작업/이탈마다 PLC START/DONE handshake 유지

첫 실사용에서는 I/O 설정 -> HOME 티칭 -> 7개 작업점 티칭 -> 저속 포인트별 검증 순서가 필요합니다.

상태: 업로드 파일 분석 `VERIFIED`, 생성 파일 구조 `PASS`, 실제 팬던트/실물 동작 `NOT_VERIFIED`
