# UR3 PACKING V5 - JOINT-AWARE

V4에서 관절 한계 문제가 발생한 원인으로 TCP pose만 저장하고 동일 pose의 여러 IK 관절 자세를 충분히 구분하지 못한 점을 반영했습니다.

변경:

1. 티칭 시 TCP pose + 실제 6축 joint position(`getj`) 저장
2. IK 계산 시 해당 티칭 joint를 `qnear`로 사용
3. 장거리 `MOVEJ`, 작업 직전/직후 짧은 구간 `MOVEL`
4. IK solution / safety limit / joint branch 검사 추가
5. 검사 실패 시 `MOTION BLOCKED`

한계: 끝점의 IK branch를 고정해도 station-to-station 경로 전체의 기구학적 자세 전환을 보장하지는 못함.

상태: 파일 구조 검사 `PASS`, 실제 팬던트/관절한계 개선 `NOT_VERIFIED`
