# UR3 PACKING V6 - HOME ROUTED

핵심 문제: P4와 P3 끝점이 각각 도달 가능해도 장거리 `MOVEL`은 두 TCP 사이의 모든 중간 pose를 직선으로 만들기 때문에 중간에 UR3가 만들 수 없는 관절 자세가 생길 수 있음.

변경:

- 사용자 정의 HOME joint posture 도입
- HOME은 factory zero pose가 아니라 실제 셀에서 안전하게 팔이 접힌 경유 자세
- `HOME_P`: HOME TCP pose
- `HOME_Q`: HOME 실제 6축 관절 자세
- 장거리 station 전환은 HOME_Q를 경유한 `MOVEJ`
- 작업점 근처 짧은 100 mm 구간만 `MOVEL`
- HOME 이동도 하나의 PLC START/DONE 포인트로 취급

예:

```text
P4 PRODUCT PICK
-> P4 RETRACT
-> HOME (MOVEJ)
-> P3 PRODUCT APPROACH (MOVEJ)
-> P3 INSERT (MOVEL)
```

상태: 실제 팬던트/실물 경로 `NOT_VERIFIED`
